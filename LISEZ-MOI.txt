MA MUSCU EN SALLE — V2

Installation / mise à jour :
1. Décompresse ce ZIP.
2. Remplace les fichiers de l’ancienne version sur ton dépôt GitHub Pages par le contenu du dossier « Ma_muscu_en_salle_V2 ».
3. Ouvre l’application sur l’iPhone et actualise-la. Si l’ancienne version reste affichée, ferme complètement l’application web puis rouvre-la. Le cache du service worker a été renouvelé pour cette V2.

Programme livré :
- Lundi : Pectoraux + Triceps.
- Mercredi : Dos + Biceps.
- Jeudi : Jambes + Fessiers.
- Vendredi : Épaules + Abdos.
- Les exercices du programme précédent sont conservés et redistribués pour limiter le chevauchement des muscles sollicités.

Fonctions :
- 28 photos intégrées dans le dossier photos/.
- Paramètres : ajouter / supprimer / renommer / réordonner les séances et exercices, déplacer un exercice vers une autre séance, modifier les charges, répétitions, séries et photos.
- Importer une photo personnelle depuis l’iPhone pour chaque exercice.
- Charges et répétitions mémorisées d’une semaine à l’autre.
- Durée indicative par séance (aucun chronomètre global).
- Chronomètre de repos, validation des séries et historique.
- Export / import des données et des photos personnalisées.

Les réglages, charges, photos personnelles et historiques sont stockés localement dans le navigateur de cet appareil. Pense à exporter régulièrement tes données pour les sauvegarder ou les transférer.
