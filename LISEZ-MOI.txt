# Ma muscu en salle — version installable iPhone

Cette version est une PWA : après une première ouverture depuis une adresse HTTPS, Safari peut l'ajouter à l'écran d'accueil. Les fichiers de l'application sont mis en cache pour une utilisation hors connexion.

## Publication gratuite (GitHub Pages)
1. Crée un compte gratuit sur https://github.com si tu n'en as pas.
2. Crée un nouveau dépôt public nommé `ma-muscu-en-salle`.
3. Décompresse cette archive et envoie **tous les fichiers** de ce dossier à la racine du dépôt (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png).
4. Dans le dépôt : **Settings → Pages**.
5. Dans **Build and deployment**, choisis **Deploy from a branch**, puis `main` et `/ (root)`, et enregistre.
6. Attends que GitHub affiche l'adresse publiée, généralement `https://TON-PSEUDO.github.io/ma-muscu-en-salle/`.

## Installation sur iPhone
1. Ouvre cette adresse dans **Safari** (pas dans le navigateur intégré d'une autre application).
2. Appuie sur **Partager** (carré avec flèche vers le haut).
3. Choisis **Sur l'écran d'accueil**.
4. Vérifie le nom « Ma muscu », active **Ouvrir comme app web** si l'option apparaît, puis touche **Ajouter**.

La publication est gratuite avec GitHub Pages pour un dépôt public. Le site doit rester publié pour que l'installation initiale et les mises à jour soient disponibles. Une fois les ressources mises en cache, l'application peut fonctionner hors connexion. Les données d'entraînement sont conservées localement dans le navigateur / l'application sur cet iPhone : pense à utiliser Exporter mes données pour en garder une copie.
